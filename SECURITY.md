# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub security advisories:

1. Go to https://github.com/GalaAI/ryozan/security/advisories/new.
2. Describe the issue, the affected version or commit, and the steps to reproduce it.

Never open a public issue, pull request or discussion for a vulnerability. Public reports put every studio running Ryozan at risk before a fix exists.

We will acknowledge the report, work on a fix, and credit you in the advisory if you want.

## Supported versions

Ryozan is early. Fixes land on `main` only. Self-hosted installs should update to the latest `main`.
